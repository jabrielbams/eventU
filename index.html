#2 Urgensi

Fragmentasi Info

Info acara tersebar (IG, WA, Poster) membuat mahasiswa sering ketinggalan info penting.

Kesulitan Daftar

Proses manual/Google Form yang tidak terintegrasi menyulitkan tracking data.

Jangkauan Sempit

Penyelenggara sulit menjangkau audiens di luar lingkaran sosial (circle) mereka.

Solusi: Sentralisasi

Dibutuhkan satu HUB terpusat untuk efisiensi total.

1
Sentralisasi Platform utama acara kampus.
2
Efisiensi Alat kelola status & pendaftar.
3
Akses Mudah Daftar, bookmark, review.

public function update(Request $request) {
  $user = Auth::user();
  $user->name = $request->name;
  if ($request->password) {
    $user->password = Hash::make($request->password);
  }
  $user->save();
  return back()->with('success', 'Updated!');
}

// EventController.php (Bookmark)
public function bookmarkEvent($id) {
  $user = Auth::user();
  if (!$user->bookmarks()->where('event_id', $id)->exists()) {
    $user->bookmarks()->attach($id);
    return response()->json(['status' => 'added']);
  }
  return response()->json(['status' => 'exists']);
}
